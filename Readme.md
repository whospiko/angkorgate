# 🇰🇭 AngkorGate

**One Gateway. Every Identity.**

AngkorGate is an open-source Identity and Access Management (IAM) platform inspired by Cambodia, built to simplify authentication, authorization, and secure access management for modern applications.

## ✨ Features

- Authentication & Authorization
- Passkeys & WebAuthn (FIDO2 / Biometrics)
- Multi-Factor Authentication (MFA / TOTP)
- User and Organization Management
- Employee and Customer Management
- Role-Based Access Control (RBAC)
- OAuth 2.0 & OpenID Connect (OIDC)
- Single Sign-On (SSO) & Social Login (Google)
- Developer API Keys Gateway & Friendly APIs
- Tamper-Evident Audit Logging

## Non Features
- Multi-Tenant

## 🛠️ Tech Stack

- **Frontend:** Next.js
- **Backend:** NestJS
- **Database:** PostgreSQL
- **Cache:** Redis

## 🚀 Vision

To provide developers with a simple, secure, and extensible open-source identity platform for managing access across applications.

## 🇰🇭 Origin

Inspired by Angkor, a symbol of Cambodian heritage, strength, and innovation.

**Built with passion in Cambodia.**
